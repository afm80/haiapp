# HaiApp — تجربة شبيهة بواتساب (بدون قنوات)

## رحلة المستخدم
1. **شاشة الترحيب** ← الموافقة على الشروط
2. **تسجيل الدخول بحساب Google** (فعّله من Firebase ← Authentication ← Sign-in method ← Google)
3. **إعداد الملف الشخصي**: الاسم + رقم الموبايل بالرمز الدولي (إلزامي ولا يتكرر) + النبذة + الصورة
   - جهات الاتصال تُطابق بالرقم مع دفتر هاتف الجوال
   - بعد تعديل `firestore.rules` انسخه إلى Firebase ← Firestore ← Rules ثم Publish
4. **الشاشة الرئيسية** بثلاثة تبويبات: المحادثات / الحالة / المكالمات

## المميزات
**المحادثات**
- قائمة محادثات مرتبة، عدّاد رسائل غير مقروءة، معاينة آخر رسالة، بحث
- رسائل لحظية، صور (معرض/كاميرا)، رد على رسالة، نسخ، تعديل، حذف
- ✓ مرسلة، ✓✓ زرقاء مقروءة (تعمل في المجموعات أيضاً)
- "يكتب..."، "متصل"، "آخر ظهور"
- فواصل التواريخ (اليوم / أمس)
- شاشة معلومات جهة الاتصال

**المجموعات**
- إنشاء مجموعة، اختيار الأعضاء، أسماء المرسلين بألوان، قائمة الأعضاء، مغادرة المجموعة

**الحالة (Status)**
- حالة نصية بخلفية ملونة أو صورة، تختفي بعد 24 ساعة
- عارض بشريط تقدم (اضغط للتنقل، اضغط مطولاً للإيقاف)
- عدد المشاهدين وقائمتهم، حذف حالتك

**المكالمات**
- مكالمات صوتية وفيديو عبر Jitsi Meet (مجاني)
- شاشة اتصال وارد داخل التطبيق (قبول / رفض)
- سجل مكالمات: صادرة، واردة، فائتة

**الإعدادات**: تعديل الملف الشخصي، معلومات الحساب، تسجيل خروج
**أخرى**: واجهة عربية RTL، وضع داكن، ألوان واتساب بهوية HaiApp

## بناء التطبيق على GitHub (بدون كمبيوتر)
المشروع فيه خطوة بناء تلقائية (GitHub Actions) تنتج لك ملف APK تثبّته على الجوال.

1. في Firebase: **Project settings** ← **Add app** ← **Android**
   - اسم الحزمة (Android package name) اكتبه حرفياً: `app.haiapp.com`
   - اضغط Register app ثم **Download google-services.json**
2. ارفع المشروع على GitHub (مستودع جديد)، وارفع ملف `google-services.json` في **جذر** المستودع (جنب `pubspec.yaml`).
3. تأكد أن مجلد `.github/workflows/build-apk.yml` انرفع. إذا ما انرفع، من GitHub اضغط
   Add file ← Create new file، واكتب في الاسم `.github/workflows/build-apk.yml` والصق محتواه.
4. افتح تبويب **Actions** ← **Build HaiApp APK** ← **Run workflow** (يشتغل تلقائياً مع كل رفع).
5. بعد 5-10 دقائق ادخل على التشغيل الناجح ونزّل **HaiApp-apk** من قسم Artifacts، فك الضغط وثبّت `app-release.apk`.

## تشغيل محلي (اختياري، يحتاج كمبيوتر)
`flutter create --org app.haiapp --project-name haiapp --platforms=android .` ثم
`python3 tools/patch_android.py` ثم `flutter pub get` ثم `dart run flutter_launcher_icons` ثم `flutter run`.

## Firebase (تم إعداده)
Authentication (Email/Password) + Firestore + محتوى `firestore.rules` منشور.

## ملاحظات مهمة
- **الصور** تُضغط وتُحفظ داخل Firestore لأن Firebase Storage صار مدفوعاً للمشاريع الجديدة.
- **المكالمات**: الاتصال الوارد يظهر فقط والتطبيق مفتوح، لأن الإشعار الخارجي يحتاج سيرفر (FCM + Cloud Functions على خطة مدفوعة). الحل المجاني لاحقاً: سيرفر Node.js صغير.
- **تسجيل الدخول بالجوال (SMS)** مجاني بحدود يومية ضئيلة، لذلك استخدمنا الإيميل. يمكن إضافته لاحقاً بنفس الملفات.
- **الخصوصية**: كل المستخدمين يرون بعضهم في قائمة جهات الاتصال (بدون مزامنة أرقام).

## المراحل القادمة
- الرسائل الصوتية، إرسال الملفات والفيديو (Supabase Storage)
- الإشعارات الخارجية
- التشفير من طرف إلى طرف، حظر المستخدمين، أرشفة وتثبيت المحادثات
